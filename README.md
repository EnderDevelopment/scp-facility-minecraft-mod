# SCP Facility Mod

A Minecraft mod that adds SCP-themed content to the game. This mod includes custom blocks, items, and a GUI to enhance the gameplay experience with SCP-themed elements.

## Installation

1. Install Fabric Loader for Minecraft 1.20.1.
2. Place the mod jar in the mods folder.

## Usage

1. Launch Minecraft with the Fabric Loader installed.
2. The mod will automatically add SCP-themed blocks and items to the game.
3. Access the custom GUI by interacting with the SCP block.
